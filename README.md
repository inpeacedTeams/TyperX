# TyperX

**Печатай естественно. Отправляй осмысленно.**

TyperX превращает подготовленный текст в живую последовательность сообщений: печатает посимвольно в активное окно, меняет ритм внутри фразы, исправляет редкие опечатки и нажимает Enter на смысловых границах. Всё локально, без аккаунта, облака и Telegram API.

## Что внутри

- семантическое разбиение русских фраз вместо случайной нарезки;
- ритм на основе WPM, логнормального шума и коротких скоростных серий;
- естественные паузы после пунктуации и между сообщениями;
- опечатки по соседним клавишам с видимым Backspace-исправлением;
- 10 встроенных ироничных шаблонов и собственная библиотека;
- стабильный предпросмотр, поиск, автосохранение и восстановление повреждённых настроек;
- глобальные F8/F9, безопасная остановка при смене активного окна;
- нативный Unicode-ввод через Win32 `SendInput`, без буфера обмена.

## Установка для разработки

Нужны Windows 10/11 и Python 3.12.

```powershell
git clone https://github.com/inpeacedTeams/TyperX.git
cd TyperX
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install -e ".[dev]"
python -m typerx
```

## Использование

Выбери шаблон или создай свой, настрой ритм и проверь сообщения в предпросмотре. Кнопка запуска сворачивает приложение и даёт три секунды на фокус Telegram. Если поле уже активно, нажми `F8`; `F9` немедленно отменяет работу.

TyperX намеренно не продолжает печатать после переключения окна. Это защищает от случайного ввода в пароль, терминал или другой чат.

## Сборка EXE

```powershell
pyinstaller --clean --noconfirm typerx.spec
```

Результат: `dist\TyperX.exe`. Каждый push проверяется на Windows в GitHub Actions и публикует сборку как artifact. Тег `v*` создаёт GitHub Release.

## Архитектура

`domain` содержит чистые модели, splitter и rhythm engine. `services` оркестрирует ввод. `platform` изолирует Win32. `persistence` делает атомарное локальное хранение. `ui` отвечает только за Qt-состояние и взаимодействие.

## Ограничения

Реальный ввод и глобальные hotkeys требуют Windows. Перед публичным релизом сборку нужно вручную прогнать в Telegram Desktop на Windows 10 и 11, включая смену фокуса, раскладки, длинные тексты и аварийный стоп.
