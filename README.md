# TyperX

**Печатай как человек. Отправляй как в живом диалоге.**

TyperX превращает подготовленный текст в естественную переписку: печатает его посимвольно в активное окно, делит на короткие смысловые сообщения и умно нажимает Enter. Всё работает локально на Windows, без аккаунта и облака.

## Почему это выглядит живо

- **Умный Enter:** делит текст по вопросам, обращениям, вводным словам и длине мысли.
- **Неровный ритм:** скорость меняется внутри слов и между сообщениями.
- **Микропаузи:** запятые, точки и длинные фразы дают естественную задержку.
- **Опечатки:** редко нажимает соседнюю клавишу, замечает ошибку, стирает и продолжает.
- **Предпросмотр:** до запуска видно, какие сообщения реально будут отправлены.
- **Аварийный стоп:** глобальная клавиша `F9` останавливает ввод в любой момент.

## Сценарий

Исходный текст:

```text
Привет как дела что делаешь чем занимаешься я например учу уроки.
```

Один из возможных планов отправки:

```text
Привет
как дела
что делаешь
чем занимаешься
я например
учу уроки.
```

Разделение слегка меняется между запусками, но не режет текст случайно посреди устойчивой фразы.

## Запуск

Нужны Windows 10/11 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
git clone https://github.com/inpeacedTeams/TyperX.git
cd TyperX
dotnet run
```

Сборка одного исполняемого файла:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Готовый файл появится в `bin/Release/net8.0-windows/win-x64/publish/`.

## Как пользоваться

1. Выбери шаблон или вставь свой текст.
2. Настрой WPM, разброс и частоту опечаток.
3. Проверь разбиение в предпросмотре.
4. Нажми кнопку старта и за 3 секунды переключись в Telegram, либо нажми `F8`, уже находясь в поле ввода.
5. `F9` немедленно останавливает печать.

## Продуктовая позиция

TyperX не маскируется под рассыльщик и не работает через Telegram API. Его сильная сторона другая: локальная автоматизация демонстраций, ролевых сценариев, тестирования чатов и заранее подготовленных диалогов. Приватность простая: текст и настройки остаются в `%AppData%/TyperX`.

Встроенные шаблоны сделаны в абсурдно-провокационном стиле, но без угроз, травли и атак на защищённые группы. Пользовательские шаблоны можно создавать и сохранять прямо в приложении.
