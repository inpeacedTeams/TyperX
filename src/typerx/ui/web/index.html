02 / ПОДКЛЮЧЕНИЕ

Твой Telegram.

Локальная сессия. Чтение истории. Никаких отправок через API.

Вход в аккаунт

Получи api_id и api_hash в разделе API development tools на my.telegram.org. Коды и пароль 2FA не сохраняются.

Чаты и история

◎

Здесь появятся твои чаты

Последние 50 сообщений

Выбери чат, чтобы увидеть контекст

Нажми на сообщение человека — его автор станет таргетом. Поддерживаются личные чаты и обычные группы; каналы, форум-топики, боты и анонимные авторы исключены. Модель получает только сообщения этого автора; ответ печатается в этом же чате. Для запуска нужен заголовок окна с названием выбранного чата, а не общий «Telegram».

03 / МОДЕЛЬ

Слова находит модель.

Подключи OpenAI-совместимый сервис или локальный сервер.

Подключение LLM

Без /chat/completions. HTTPS обязателен, кроме localhost.

Проверка отправляет только тестовую фразу, без переписки.

Знай, куда уходит контекст

Сессия Telegram остаётся на устройстве. История выбранного чата передаётся на твой base URL только во время работы AI-режима.

05 / РУЧНАЯ ПЕЧАТЬ

Твои слова. Живой набор.

Без нейросети и Telegram API. Использует скорость и длину сообщений с главного экрана.

Открой нужное поле в другом приложении и нажми F8. Не переключай окно во время печати. Старый редактор и Monkeytype доступны через python -m typerx --legacy.
