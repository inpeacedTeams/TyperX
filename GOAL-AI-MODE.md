# TyperX — AI-режим: цель

## Суть

Пользователь отвечает людям в Telegram не сам, а через связку «личность (системный промпт) → нейросеть → TyperX». Вход — реальная переписка с выбранным человеком. Выход — напечатанные вживую сообщения, неотличимые от ручного набора. TyperX остаётся единственной точкой вывода: нейросеть ничего не отправляет сама, она лишь отдаёт текст печатающему движку.

## Функциональные блоки

1. **Аккаунт Telegram** — вход по номеру, коду и 2FA; кнопка «Загрузить чаты»; подгрузка последних 50 сообщений любого чата; выбор таргета, за которым следит нейросеть.
2. **Настройка LLM** — base URL, API-ключ, модель; кнопка «Проверить» с понятным результатом.
3. **Системные промпты** — несколько личностей одновременно; сохранение наборов как пресетов, переключение в один клик.
4. **Живой цикл** — режим нейросети включён → Telethon читает сообщения таргета → нейросеть генерирует ответ с учётом личности и истории → ответ режется на сообщения по настраиваемому числу слов → TyperX печатает их с настраиваемым WPM через драйвер, с паузами и человеческим ритмом.

## Дизайн

UI/UX нужно **полностью переделать с нуля и оформить по красоте**: современный вид, аккуратные окна под каждый блок (вход в Telegram, чаты, LLM, пресеты), понятная индикация живого цикла (таргет написал → нейросеть думает → TyperX печатает), никакого вида «формочка на Qt по умолчанию».

Важно: интерфейс делается **на HTML/CSS/JS внутри десктоп-приложения** (вебвью внутри нативного окна), а не на Qt-виджетах — чтобы была полная свобода по вёрстке, анимациям и стилю.

## Границы

- Печать только через движок TyperX, никаких прямых отправок через Telegram API.
- Отвечает только выбранному таргету.
- F9 и защита от смены окна не отменяются нейросетью.
- Сессия и ключи хранятся локально.

## Критерий готовности

Пользователь включает режим, уходит пить чай — таргет получает связные ответы «в характере» пресета, напечатанные с человеческим ритмом и разбитые на естественные сообщения, и не догадывается, что за клавиатурой никого нет.
